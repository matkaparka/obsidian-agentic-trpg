## 2. 战役记忆（`src/table/memory.ts`）

- **前情**：每幕结束（`end_scene` / `end_game`，经 `applySceneEnd`）存一条：GM 的 `summary`（含秘密，只给 GM）、GM 写的 `public_recap`（玩家知道的版本）、桌面客观记下的几条（倒下的怪物、升级、拿到 / 付出的东西）、这幕走了几轮。最多 12 幕，同一幕再结束就覆盖。
- **世界事实**：GM 用 `note_fact { text, key?, public? }` 登记（谁欠谁、哪个 NPC 知道什么、哪条路被堵了），同 key 再写 = 更新，`drop_fact { key }` 删，最多 30 条，满了淘汰最旧的。`public: true` 玩家也知道，不写 = 只有 GM 知道（伏笔、秘密）。
- **谁看到什么**：GM 的系统提示里有【前情】（最近 3 幕全文，更早的压成一句）和【已记下的世界事实】；玩家视角里有【前情（你们都记得的）】——**只有 `public_recap` 或客观记录，和 `public: true` 的事实**，GM 的 summary 和私有事实不会进来（有测试）。
- `end_scene` 新增可选参数 `public_recap`；GM 提示里写明了「玩家也看得到，只写他们知道的」。
- **存档**：`table.json` 多一个 `memory`；老存档没有就从记录里的「场景结束：…」补出前几幕（只有 GM 版，没有公开版，所以玩家那边看不到）——**现在这个存档重启后第一幕的前情就是这样补出来的**。
- 没有做：任务线 / 日志面板、前情摘要的二次压缩（目前靠 clip）、玩家自己写笔记。

## 3. 物品 / 金币 / 战利品

数据：`Actor.inventory`（物品堆：名字、数量、类别、说明、价值、`use`）和 `Actor.coinsCp`（铜币总数，1 gp = 100 cp），在 `src/rules/inventory.ts`；进存档（老存档没有就是空）。

- **GM 工具**：`give_item`（to、name、qty、kind、desc、value_gp、`heal`、`note`、`loot_id`）、`take_item`、`give_gold`（to 可以是 `party` = 平分，余数给第一个人）、`take_gold`（钱不够就失败，不扣成负数）。上限：数量 1–99、一次最多 10000 gp。提示词里写明「旁白里说找到了不算，要用工具发」。
- **玩家用物品**：`item` 行动里提到背包里有规则效果的东西（治疗药水，`heal: 2d4+2`），桌面结算——花一个动作、用掉一件、掷骰回血，可以喂给队友（倒下的队友会醒，战斗里要相邻）。没有规则效果的东西（银衣扣）只是「拿出来」，不花动作、不用掉。背包里没有的东西不生效。以前 `item` 行动是空壳。
- **玩家看到什么**：玩家视角里有【你的背包】（金币 + 物品）和一句「背包里没有的东西，你就是没有」；「现在能做的事」里每个有效果的物品一行。
- **战利品清单**：场景 md 的 `## 战利品`，一行一件：`- 名字[ ×数量]｜类别｜说明｜在哪里`；类别可省（消耗品 / 任务物品 / 财宝 / 杂物 / 武器 / 护甲）；最后一栏永远是位置；钱写成 `- 碎银 9 gp｜红帐里的战利品箱`；说明里写「恢复 2d4+2」就是治疗药水。这份清单**只给 GM**，GM 在玩家搜到、拿到之后才发，`loot_id` 写清单里的 id，发过的标【已发】、不能重复发（存档里记着）。五幕的清单我按各幕「GM 秘密」里已有的内容写了（碎银 9 gp、银衣扣、炭笔地图、50 gp 碎银、报酬 10 + 10 gp…）。
- **起始物品**：角色卡 json 顶层可选 `"kit": { "gold": 15, "items": [{ "name": "治疗药水", "qty": 1, "kind": "consumable", "heal": "2d4+2" }] }`。我给两张 lv3 卡各加了 15 gp 和一瓶治疗药水（不合适直接删这个字段）。**存档里已有的角色不会被 kit 覆盖**（物品是状态，和人设不同），所以当前这个存档的两个角色是空背包，要 `--fresh` 才有。
- **画面**：面板上 AC 旁边多一个金色金币标签（没钱不显示）；拿到东西 / 钱弹绿色提示（「获得 矮人银衣扣」「+4 gp 5 sp」）；付出和用掉的只在桌面记录里。截图 `docs/shots/rounds/gold-chip-crop.png`。事件 `loot` 会作为系统消息发给 Helixus。
- 桌面记录和前情：每次拿到 / 付出 / 用掉都会在 transcript 里记一行，并进这一幕的客观记录（幕结束时进前情）。
- 没有做：商店 / 定价、负重、魔法物品的规则效果（只有治疗药水和「叙事型消耗品」）、玩家之间交换物品（现在靠 GM 的 `give_item` / `take_item`）、武器 / 护甲的穿戴（角色卡的装备还是构建器算）。
