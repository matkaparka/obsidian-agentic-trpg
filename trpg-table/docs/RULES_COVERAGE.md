# 规则覆盖（2014 / SRD 5.1）

写于 2026-10-18，对应 `src/rules/` 的实现。"自动" = 引擎结算，"GM 裁定" = 引擎只记状态 / 给说明、靠 GM 口头处理，"没有" = 没做。
每一条都有测试：`test/rules.test.ts`、`test/combat5e.test.ts`、`test/features5e.test.ts`（构建器和法术各有自己的测试文件；优势 / 劣势 / 固定加值类法术在 `test/rollmod5e.test.ts`）。

## 战斗流程

| 规则 | 状态 |
| --- | --- |
| 先攻（同值比敏捷）、回合、轮数、突袭（第一回合动不了、不能反应） | 自动 |
| 背包与金币（2026-10-19）：物品堆 + 铜币进存档；GM 工具给 / 收；治疗药水玩家自己喝或喂队友（花动作、掷骰、用掉一件）；其它物品只是叙事，由 GM 裁定；没有商店、负重、魔法物品效果 | 自动（效果有限，见 `HANDOFF_CAMPAIGN_STATE.md` §3） |
| 回合计（2026-10-19）：探索也分轮——每轮每个 PC 各一次 → 世界回合（场上生物 + 到点的环境条目）→ 关轮；战斗里先攻转完一圈，到点的环境再各动一次；战斗外一轮≈1 分钟，有回合数的状态按 10 个战斗轮走；战斗外每个 PC 的回合开始时动作 / 附赠 / 反应 / 移动恢复、回合末做豁免 | 自动（环境条目怎么演由 GM 裁定，见 `HANDOFF_ROUNDS.md`） |
| 动作 / 附赠动作 / 反应 / 移动记账；Attack 动作的多次攻击（额外攻击、怪物多攻套路）；动作如潮 | 自动 |
| 疾走、闪避（对你攻击劣势、敏捷豁免优势）、撤离、躲藏（隐匿对被动感知）、协助（下一次攻击优势） | 自动 |
| 借机攻击：走出敌对生物触及范围时自动结算（PC 和怪物都是），撤离不引发，每个反应一次，被打倒就停在半路 | 自动 |
| 擒抱、推撞、挣脱：运动对抗运动 / 杂技，怪物擒抱有固定脱逃 DC；擒抱者倒下 / 失能 / 离开触及就松手 | 自动 |
| 副手攻击（双武器战斗）、鲁莽攻击、神圣斩击、震慑拳（攻击时在 detail 里声明） | 自动 |
| 倒地后站起来花一半速度；力竭速度减半 / 归零；疾走翻倍 | 自动 |
| 先攻外的"周围环境"：陷阱、坠落、窒息、火焰 | GM 裁定（`damage_dice` 给公式，引擎掷骰） |

## 状态

15 个 SRD 状态 + 躲藏。目盲、魅惑、耳聋、恐惧、擒抱、失能、隐形、麻痹、石化、中毒、倒地、束缚、震慑、昏迷、力竭 1–6 级：
对攻击、检定、豁免、速度的实际影响按 SRD 写进 `logic/conditions.ts`（中毒和恐惧只管攻击和属性检定，**不管豁免**）。
免疫的状态加不上；失能打断专注；状态持续时间按轮倒数。

## 职业与种族特性

自动的：额外攻击、偷袭、回气、动作如潮、不屈、狂暴（抗性 / 伤害 / 优势 / 不能施法 / 一回合不攻击就结束）、鲁莽攻击、危险感知、
野蛮暴击、狡诈动作、灵巧闪避、直觉闪避、可靠才能、杂艺、圣疗、神圣斩击、保护光环、驱逐不死生物、保全生命、
武艺、疾风连击、坚忍防御、疾风步、震慑拳、诗人激励（差一点成功时自动加）、龙息、半身人幸运、精灵血统 / 勇敢 / 矮人韧性 / 侏儒狡黠、
不屈耐力、野蛮攻击、战斗风格（弓箭手 / 决斗 / 巨武器 / 双武器）、痛击魔爆、奥术回复、契约魔法。
完整列表和说明见 `src/rules/features/registry.ts`。

**其它职业 / 种族特性不自动结算**（野性变形、术法点和超魔、宿敌 / 天生探险家、神圣感知、各子职业的专属能力…）：
它们会作为特性出现在角色卡上，由 GM 口头裁定。

## 角色构建

`src/rules/build/`：种族（15 个种族 / 亚种）+ 背景（13 个）+ 职业与等级（12 个 SRD 职业 1–20 级，含兼职）+ 子职业（SRD 12 个 + ODM 复述的 101 个）+ 属性 → 完整角色卡。
自动算：属性（种族加值、升级提升、专长、上限）、熟练、豁免、技能与专精、HP、AC（护甲 / 盾 / 无甲防御 / 防御风格）、速度、攻击列表、额外攻击次数、偷袭骰、
法术位（单职业、多职业合并、契约魔法）与法术数量上限、永久准备法术、资源（狂暴 / 气 / 圣疗池 / 诗人激励…）、特性 id、抗性免疫。
带合法性检查（errors / warnings），每个"不给就自动选"的地方都确定可复现。没做的见 `src/rules/build/README.md`。

## 怪物

14 个 SRD 怪物，带多攻套路（强盗首领、斥候、沙华鱼人、活化盔甲）、远程攻击射程、命中状态（狼撞倒、食尸鬼麻痹、巨蟹擒抱）、
毒伤豁免减半（巨蜘蛛）、群体战术、嗜血狂热、不死坚韧、灵巧逃脱（附赠动作撤离 / 躲藏）、魔法抗性（豁免优势）。
其它特性只是文字说明（格挡反应、蛛网、鼠群半血减伤…），GM 裁定。

## 明确没有的

反应类法术的触发（护盾术要 GM 手动施放）、预备动作、骑乘和载具、追逐、材料成分、仪式施法、法术书抄录、
多职业的生命骰（只按一种骰）、装备重量 / 力量要求、魔法物品（除了武器的 `magicBonus`）、2024 规则。
