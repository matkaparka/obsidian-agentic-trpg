# 银鸥号的残骸

一场风暴把商船“银鸥号”拍在了礁石上。两名冒险者（3 级）在午夜爬上了倾斜的甲板。
船里有一口封死的圣物箱；船员都死了，但船没有空。海里有东西绕着船游，货舱里有东西在等。

这是一个 1–2 小时的 one-shot，三幕：甲板 → 货舱 → 岸边洞穴。适合 2 名 3 级角色。

## 节奏建议

- 第一幕：探索 + 一场小遭遇（沙华鱼人从船舷翻上来），5–15 分钟。
- 第二幕：货舱守卫（活化盔甲 + 食尸鬼），拿到圣物箱，10–20 分钟。
- 第三幕：岸边洞穴（沙华鱼人 + 巨蟹），收尾与结局，15–25 分钟。
- 中间可以短休一次（在货舱清空之后、去洞穴之前）。

## 秘密主线

圣物箱里封着“溺亡者之眼”——一颗能让海水听见名字的珠子。沙华鱼人想把它扔进深海，商会想把它带回去。
玩家可以毁掉、带走、或交给岸上的水手。没有唯一正确答案；GM 按玩家的选择收尾。

## GM 备注

- 三位 NPC 的动机：沙华鱼人（夺回圣物）、活化盔甲（执行最后一条命令）、食尸鬼船长（守住船长室）。
- 不要一次把三幕的秘密都倒出来；每次只给玩家能看见的线索。
- 地图是原创占位图；正式直播前可以用用户选定的地图替换（见 `LICENSES.md`）。
